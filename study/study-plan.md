## 1. Evaluation (what your mock actually showed)

> Note: the typed/printed answer sheet was your **corrected** copy. The notebook pages are
> your **original** answers with the grader's pen. The analysis below uses the originals.

### What's genuinely solid (don't over-study these)
- **Gerund formation** (-ando / -iendo): visitando, tomando, nadando, escuchando,
  descansando, haciendo — all correct.
- You correctly figured out *which* verb goes in each blank.

### What's costing you points (in priority order)
1. **Present progressive uses the wrong helping verb.** You wrote *ser* (soy/son/eres) or
   just a pronoun (nosotros/el/la) + gerund. Grader: "estar + ___".
   → Rule: **progressive = estar (estoy/estás/está/estamos/están) + gerund.** Never *ser*.
   Never a gerund by itself ("Yo durmiendo" → "Yo **estoy** durmiendo").
2. **You left verbs as infinitives.** You wrote decir, conseguir, pedir… Grader: "Conjugate!"
   → Always conjugate the main verb to match the subject.
3. **You over-applied stem changes to "nosotros."** "prefierimos" → **preferimos**,
   "vuelvemos" → **volvemos** (grader: "don't change for nosotros").
   → Rule: stem verbs change in **every form EXCEPT nosotros/vosotros.** (And in the forms
   that *do* change, get the vowel right: consigue, pide, repite, almuerzo.)
4. **Double verbs:** the second verb stays an **infinitive.** "puede conduce" → puede
   **conducir**; "puede cocina" → **cocinar**.
5. **"X y yo" = nosotros, and word order.** "Mi y mi amigo juegan" → "Mi amigo y yo
   **jugamos**." (*mi* means "my" and can't stand alone — it's "mi amigo **y yo**.")
   Collective nouns are singular: "mi familia **duerme**."
6. **ser vs estar:** feelings/conditions/location = **estar**; origin/characteristics/dates
   = **ser**. (somos de California; están contentos; estamos en México; el hotel es moderno.)
7. **de vs desde:** for "from a place" use **de**. "desde India" → **de India**;
   "desde la tienda" → **de la tienda**.
8. **Pronouns & accents:** Ello → **Ellos**; el → **él**; puedó → **puedo**.
9. **Articles & agreement:** don't drop articles (un vestido); match gender/number
   (la camisa **morada**, las habitaciones **cómodas**).

## 2. How to write grammatically correct sentences (your #1 goal)

Run this **6-step checklist** in your head for *every* sentence you write:

1. **Subject** — who? Singular or plural? ("X y yo" = nosotros.)
2. **Main verb** — conjugate it to match the subject. Is it a stem-changer?
   (If so, change the stem in all forms **except nosotros/vosotros**.)
3. **Second verb?** — keep it an **infinitive** (puede **cocinar**).
4. **ser or estar?** — use the mnemonic below.
5. **Nouns** — add the article (el/la/los/las) and make adjectives agree (gender + number).
6. **Proofread** — accents and spelling.

### ser vs estar mnemonic
- **SER = DOCTOR**: **D**escription, **O**ccupation, **C**haracteristic, **T**ime/date,
  **O**rigin, **R**elationship. *(El hotel es moderno. Somos de California. Hoy es sábado.)*
- **ESTAR = PLACE**: **P**osition, **L**ocation, **A**ction (progressive: estar + gerund),
  **C**ondition, **E**motion. *(Estamos en México. Están contentos. El equipaje está perdido.)*

### Free practice material (use alongside the flashcards)
- **Conjuguemos.com** — drills for present tense + stem-changers + preterite. Best for #2/#3.
- **SpanishDict.com** — look up any verb to see every conjugation; has grammar lessons +
  quizzes for ser/estar, object pronouns, preterite.
- **StudySpanish.com** — clear ser/estar and pronoun lessons with tests.
- **Self-check writing drill:** write 5–10 sentences a day using the 6-step checklist, then
  paste them into the SpanishDict translator to catch errors. Rewrite the wrong ones.

## 3. The flashcard decks

Two decks, in `front,back` (comma) format for **ZemoMemo**, designed so you **type every
answer** — no flip-only cards. The front always tells you exactly what to type.

| File | What it is |
|------|------------|
| `grammar-deck.txt` | 124 grammar cards (comma format — use this in ZemoMemo) |
| `vocab-deck.txt` | 95 vocab cards (comma format — use this in ZemoMemo) |
| `grammar-deck.tsv` / `vocab-deck.tsv` | Same cards, **tab**-separated (backup for Quizlet or if commas misbehave) |

### How to read a card front
- "Write only the verb / one word" → type a single word.
- A template like `yo ____ / tú ____ / él ____ / nosotros ____ / ellos ____` → type each form
  in that order separated by ` / ` (spaces around the slash), e.g. `estoy / estás / está / estamos / están`.
- "Translate to Spanish: …" → type the full sentence. The front gives you the verb and
  subject so there's exactly one expected answer.

### Grammar deck sections (in order)
A. Present progressive (estar + gerund) · B. Always conjugate / present endings ·
C. Stem-changers + the nosotros exception · D. Double verbs · E. "X y yo" = nosotros ·
F. ser vs estar · G. de vs desde · H. Subject pronouns + accents · I. Articles & agreement ·
J. Direct & indirect object pronouns (last 2 cards marked STRETCH = optional) ·
K. Preterite.

### How to import into ZemoMemo
1. Make a new deck (one for grammar, one for vocab).
2. Choose the **import / paste / bulk-add** option.
3. Open `grammar-deck.txt`, select all, copy, and paste it in.
4. Set the separator **between term and definition = comma**, and **between cards = new line**.
5. Import, then study in **typing mode**.
- If the comma version ever splits a card wrong, use the `.tsv` file instead and set the
  separator to **Tab**.
- In **Quizlet**: New set → Import → "Between term and definition: **Tab**", "Between cards:
  **New line**" → paste the `.tsv` file.

### Note on accents
Answers keep correct accents (á, é, í, ó, ñ, ¿, ¡) because they matter on the test. If your
app marks an answer wrong only because of a missing accent, turn on "ignore accents" in its
settings if it has one — don't lose sleep over accent-only typos while drilling.

## 4. The 2-day schedule (Day 3 = optional buffer)

Short, frequent sessions work best for slow memorization. Mix grammar (apply) with vocab
(memorize) instead of doing one for hours.

### Day 1 — verbs & the present tense
- **Grammar deck A–C** (present progressive, always-conjugate, stem-changers + nosotros).
  This is your biggest point loss — spend the most time here.
- 15–20 min on **Conjuguemos** present-tense + stem-change drills.
- **Vocab Tier 1** (the verbs + ser/estar adjectives) in 3–4 short bursts.
- Write **5 sentences** using the 6-step checklist; self-check in SpanishDict.

### Day 2 — everything else + preterite
- **Grammar deck D–K** (double verbs, "X y yo," ser/estar, de/desde, pronouns, articles,
  object pronouns, preterite).
- Finish **Vocab Tier 1**, then **Tier 2** (clothing, food, travel words).
- Write **10 sentences** + one short paragraph like the Escribir task (what you do on
  Sunday mornings + two things your family wants to do next weekend). Self-check.

### Day 3 (if you have it)
- Re-study only the cards you keep missing (star/flag them in the app).
- One timed write-up under exam-like conditions.
